canary exec
===========

Execute a single job

.. code-block:: console

   usage: canary exec [-h] [--session SESSION] spec
   
   Execute a single job
   
   positional arguments:
     spec               Run this spec ID
   
   options:
     --session SESSION  Run the job in this session
     -h, --help         Show this help message and exit.
