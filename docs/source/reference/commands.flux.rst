canary flux
===========

Run Canary tests through Flux

.. code-block:: console

   usage: canary flux [-h] {run,exec} ...
   
   Run Canary tests through Flux
   
   positional arguments:
     {run,exec}
     run         Run Canary jobs individually inside a Flux allocation
     exec        Execute one Canary job inside a Flux allocation
   
   options:
     -h, --help  Show this help message and exit.
