canary init
===========

Initialize a Canary session

.. code-block:: console

   usage: canary init [-wh] [path]
   
   Initialize a Canary session
   
   positional arguments:
     path        Initialize session in this directory [default: .]
   
   options:
     -w          Wipe any existing session first
     -h, --help  Show this help message and exit.
