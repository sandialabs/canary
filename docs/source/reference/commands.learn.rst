canary learn
============

Query installed Canary capabilities and skills

.. code-block:: console

   usage: canary learn [-h] topic ...
   
   Query installed Canary capabilities and skills
   
   positional arguments:
     topic
     capabilities (capability, caps, cap)
                           Query the aggregated Canary capability tree
     skills (skill)        Query the aggregated Canary skill tree
   
   options:
     -h, --help            Show this help message and exit.
