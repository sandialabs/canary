canary help
===========

Get help on canary and its commands

.. code-block:: console

   usage: canary help [-h] [--all] [--pathspec] [--pathfile]
   
   Get help on canary and its commands
   
   options:
     --all       list all commands and options
     --pathspec  help on path spec syntax
     --pathfile  help on path file syntax
     -h, --help  Show this help message and exit.
