canary describe
===============

Print information about a job file, job

.. code-block:: console

   usage: canary describe [-h] [-o option] testspec
   
   Print information about a job file, job
   
   positional arguments:
     testspec    Job file or job spec
   
   options:
     -o option   Turn option(s) on, such as '-o dbg' or '-o intel'
     -h, --help  Show this help message and exit.
