canary batch
============

Manage and run job batches on an HPC scheduler

.. code-block:: console

   usage: canary hpc [-h]  ...
   
   Manage and run job batches on an HPC scheduler
   
   options:
     -h, --help  Show this help message and exit.
   
   subcommands:
     
     run         Batch jobs and submit to HPC scheduler
     exec        Execute (run) the batch
     info        Show HPC scheduler basic info
     log         Print the batch log
     help        Additional canary_hpc help topics
