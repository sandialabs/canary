canary gc
=========

Garbage collect (remove) files generated by cases with status 'success'

.. code-block:: console

   usage: canary gc [-h] [--dryrun]
   
   Garbage collect (remove) files generated by cases with status 'success'
   
   options:
     --dryrun    Show what would be removed by garbage collection, but don't perform deletion
     -h, --help  Show this help message and exit.
