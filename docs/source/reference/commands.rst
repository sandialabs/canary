Command Reference
=================

The following pages are generated from Canary's command-line parser.

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Command
     - Description
   * - :ref:`canary batch <commands.batch>`
     - Manage and run job batches on an HPC scheduler
   * - :ref:`canary check <commands.check>`
     - Run canary's internal checks
   * - :ref:`canary collect <commands.collect>`
     - Find and generate test cases
   * - :ref:`canary commands <commands.commands>`
     - List or generate reference documentation for Canary commands
   * - :ref:`canary config <commands.config>`
     - Get and set configuration options
   * - :ref:`canary describe <commands.describe>`
     - Print information about a job file, job
   * - :ref:`canary dist <commands.dist>`
     - Manage testing across a distributed pool of machines
   * - :ref:`canary docs <commands.docs>`
     - open canary documentation in a web browser
   * - :ref:`canary edit <commands.edit>`
     - open test files in $EDITOR
   * - :ref:`canary exec <commands.exec>`
     - Execute a single job
   * - :ref:`canary fetch <commands.fetch>`
     - Fetch canary assets
   * - :ref:`canary find <commands.find>`
     - Search paths for test files
   * - :ref:`canary flux <commands.flux>`
     - Run Canary tests through Flux
   * - :ref:`canary gc <commands.gc>`
     - Garbage collect (remove) files generated by cases with status 'success'
   * - :ref:`canary help <commands.help>`
     - Get help on canary and its commands
   * - :ref:`canary hpc <commands.hpc>`
     - Manage and run job batches on an HPC scheduler
   * - :ref:`canary info <commands.info>`
     - Print information about test session
   * - :ref:`canary init <commands.init>`
     - Initialize a Canary session
   * - :ref:`canary learn <commands.learn>`
     - Query installed Canary capabilities and skills
   * - :ref:`canary location <commands.location>`
     - Print locations of test files and directories
   * - :ref:`canary log <commands.log>`
     - Show the session or a job's log file
   * - :ref:`canary query <commands.query>`
     - Query Canary job or session lock files
   * - :ref:`canary rebaseline <commands.rebaseline>`
     - Update baseline files from existing test results
   * - :ref:`canary report <commands.report>`
     - Create reports from Canary results
   * - :ref:`canary rm <commands.rm>`
     - Remove Canary workspace
   * - :ref:`canary run <commands.run>`
     - Find and run tests from a pathspec
   * - :ref:`canary select <commands.select>`
     - Create tagged selection of tests
   * - :ref:`canary selection <commands.selection>`
     - Create selections of tests to run
   * - :ref:`canary status <commands.status>`
     - Print information about a test run
   * - :ref:`canary tree <commands.tree>`
     - list contents of directories in a tree-like format
   * - :ref:`canary view <commands.view>`
     - Manage a workspace's view
