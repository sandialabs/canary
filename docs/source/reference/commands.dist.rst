canary dist
===========

Manage testing across a distributed pool of machines

.. code-block:: console

   usage: canary dist [-h]  ...
   
   Manage testing across a distributed pool of machines
   
   options:
     -h, --help  Show this help message and exit.
   
   subcommands:
     
     status      Show the status of machines in pool
     run         Run test cases across the distributed pool
     exec        Execute batch on remote machine
