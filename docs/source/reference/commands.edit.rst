canary edit
===========

open test files in $EDITOR

.. code-block:: console

   usage: canary edit [-h] testspec
   
   open test files in $EDITOR
   
   positional arguments:
     testspec    Job file or job spec
   
   options:
     -h, --help  Show this help message and exit.
