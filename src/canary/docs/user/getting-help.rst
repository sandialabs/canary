Getting help
============

``canary`` has several :ref:`subcommands <canary>`.  To get the list of subcommands, issue

.. doc-run::
   :script: ["canary -h"]


To get help on an individual subcommand, issue, for example:

.. doc-run::
   :script: ["canary run -h"]
